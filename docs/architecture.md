# 运行模式（v4.6 当前形态）

本文描述现役版本的完整工作方式。读这一篇就知道鱼是怎么活的。

## 一、总览：脑手分离 + 双模读取

```
                 每条消息的处理路径
                 ─────────────────
                        │
              读会话预览（~1s，UIA 成本低）
                        │
              预览变了？──没──→ 跳过（群安静）
                        │ 变了
                        ▼
              是媒体占位？[图片]/[表情]/[视频]
                        │ 是
                        ▼
              直接跳过（鱼看不见，不瞎评）
                        │ 否
                        ▼
              完整短文本且无@大肥鱼？
                 ┌──是──┴──否──┐
                 ▼              ▼
        预览捷径            进聊天窗口
     （零窗口渲染）        （真实消息对象，~9s）
                 │              │
                 └──────┬───────┘
                        ▼
                  鱼脑决策（HTTP + 共享密钥）
                        │
              ┌─────────┼──────────┐
              ▼         ▼          ▼
           mention   active      沉默
          （必回）  （判官）   （不发）
              │         │
              ▼         ▼
        完整人格生成   瘦判官 → 决定说→完整人格生成
              │         │
              └────┬────┘
                   ▼
            橡皮擦（撕草稿/黑名单/断尾）
                   ▼
            气泡拆分（[[next]] 协议）
                   ▼
            发送（引用优先，@ 按需；无多余扫描）
```

## 二、鱼脑（FastAPI 服务）

部署在你的服务器（或单机模式的同机 127.0.0.1）。

**决策三层**：

1. **mention**：文本含"大肥鱼"或引用了鱼 → 必回，并进入/续期活跃周期
2. **active（活跃周期内）**：瘦判官（不带人格卡，省 prefill）决定接不接；
   决定接才用完整人格生成。连续 3 次"跳过"自动下头；25 秒主动间隔防刷屏
3. **沉默**：周期外每条消息 5% 概率苏醒；每日 100 条保险丝

**认知组件**：

- 人格卡 + 热梗词典 + 动态黑话学习（每日 23:00 扫日志，两次出现才入库）
- 每群记忆：30 条消息沉淀一次【近期话题 + 成员画像】，JSON 持久化
- 效果追踪：鱼发言后 60 秒群反应回注后续判官
- 可见自己说过的话（防复读）；占位消息不触发主动（防幻觉）

**输出整形**：双层括号草稿撕掉、AI 味黑名单整句删除、超长压缩不断尾、
「说"..."」外壳剥除、[[next]] 多气泡协议。

**可观测**：/fish/health（版本号）、/fish/stats（延迟分布）、/fish/board（单页面板）、
/fish/logs（按会话+日期的 jsonl 聊天日志，含 latency_ms/llm_ms）。

## 三、鱼手（Python，Windows 挂机）

**消息检测三层**：

1. **哨兵**：会话列表预览（~1s）判断有无新消息
2. **捷径**：完整短文本直接构造消息（零窗口渲染）
3. **完整流程**：截断/@/需要引用时才进窗口读真实对象（~9s，只在这时付）

**新旧判断**：水位线（消息对签名锚点），不看 UI id——重渲染/重复内容都不受影响；
锚点丢失时用预览兜底。

**发送**：引用优先（quote 挂原话，无输入框 @ 动作）；@ 仅在必要时；
气泡间仅 0.3s 技术间隔；不传 who（当前已在群内）。

**保活**：窗口保养（每 3 分钟 force 重进）、分阶段计时（慢环节点名）、
心跳文件、fish_hand.log（2MB 轮转）、fish_error.log（崩溃证据）。

## 四、运维（全自动）

- **start.bat**（双击）：先跑 update.py 全套更新（哈希比对），再跑 watchdog.py
- **watchdog.py**：拉起鱼手、崩溃 5s 重拉、心跳超时 150s 强杀重启
- **disconnect-safe.bat**：断开 RDP 前以管理员运行，tscon 移交控制台保持渲染
- 挂机宝重启链：autologon → 微信自启自登 → start.bat 开机项

## 五、变更纪律

版本号必增（HAND_VERSION / WATCHDOG_VERSION / BRAIN_VERSION）；
每个行为修改配日志；先跑 `pytest tests/ -q`（30 例）；异常必须进日志文件。
