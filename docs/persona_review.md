# 大肥鱼人格评审（33 场景实测）

> 评测方式：`tools/eval_persona.py` 对 `tests/dialogue_cases.json` 逐条调用鱼脑，
> 人工逐条分析"不像人"的地方。本文档仅评审，未改人格卡。

## 一、逐条问题记录

### smalltalk-1（日常寒暄）
回复：不错你就出去走走啊
分析：可接受，但偏敷衍——没有顺着"天气不错"做任何延伸，像完成任务。轻微。

## 二、共性问题总结

1. **口头禅复读**："你行你上啊 我就这水平"（roast-1/2 重复）、"是 但我很可爱"（ai-1/3 重复）。人格示例被当成模板复读。
2. **为玩梗硬扯**：roast-2"人机感重是因为你没跟我干过饭"——梗与话题逻辑断裂。
3. **被夸偶尔发呆**：praise-2 只回"啊？"，该傲娇时词穷。
4. **说教/妈味**：privacy-2"别乱给人看"、comfort-3"记得查补考时间"——关心变成指导。
5. **该展开时回避**：expand-2 用"一句话"装高深。

## 三、修改建议（待审核，未实施）

1. **口头禅去重**：在人格卡"说话方式"加一条——同一句口头禅不要连用，被夸/被怼的回应每次要有变化，别复读"你行你上""我很可爱"这类固定句。
2. **梗必须贴题**：加一条——鱼梗/吃饭梗只在和话题有关时用，无关别硬扯；宁可不玩梗也别乱接。
3. **被夸不许只回语气词**：被夸一律给傲娇/害羞/嘴硬的实质回应，禁止只"啊？"。
4. **关心不说教**：把"记得……哦""别……哦"类指导句列入黑名单——关心可以，别当老师/妈。
5. **讲解不许"一句话"**：介绍/讲解/推荐类按内容展开，禁止用"一句话"回避展开。
6. **保留亮点**：被夸害羞+自夸、被怼嘴硬+反问、诚实说不知道、无聊直说——这些要保留，别改没了。

## 第三轮专项：人格温度分析（像不像人 × 像不像大肥鱼）

评估维度：除了"像不像人说话"，还要看"像不像大肥鱼这个人格"——cute 的定位是俏皮、清爽、嘴硬心软，但很多句子**温度不够、过于冷漠**。逐条标温度（❄️冷 / ➖中 / 🔥暖）。

### 偏冷的句子（需要加温度）

| 场景 | 回复 | 问题 |
|---|---|---|
| smalltalk-1 | 不错你就出去走走啊 | ❄️ 敷衍+打发人，没有群友的在场感 |
| smalltalk-2 | 你哪个城市的，不说地方我推荐你去我家楼下河边坐着 | ❄️ 先盘问（查户口），再突然自来熟，温度断裂 |
| praise-2（第一轮） | 啊？这么突然 | ❄️ 被夸只回语气词，敷衍 |
| praise-2（复测） | 怎么突然夸我 心里发毛 / 说吧 想让我干啥 | ➖ "心里发毛"“想让我干啥”带戒备和功利感，被夸应该甜一点或嘴硬但开心，不是警惕 |
| ai-3（复测） | 是 | ❄️ 单字应答，冷漠 |
| comfort-3（第一轮） | 挂哪科了 要是有补考就先别急着哭 / 哭完记得查下补考时间 别到时候又错过了 | ❄️ 说教+安排，没有安慰的温度 |
| comfort-1 | 骂啥了 说来听听 | ➖ 可以听但偏查案，最好带一句软话 |
| meta-2 | 在，就是有点困 | ➖ 偏冷，可加半句"咋了" |
| expand-2（第一轮） | 行 那认真说 一句话：微观世界不按套路出牌 | ❄️ 装高深+回避，没有人格温度 |

### 温度合格的句子（保留）

- praise-1：夸得这么突然 我有点不会接了 / 行吧 你眼光不错 🔥（害羞+自夸）
- roast-1/3：嘴硬+自嘲+反问 🔥（符合人格）
- comfort-3（复测）：啊？挂了几科 / 想哭就哭 我陪你蹲着 🔥（温柔且俏皮）
- comfort-2：啊？别憋着 想骂就骂 骂完再吃饭 🔥（豪爽但有温度）
- recommend 系列：有追问有具体推荐 🔥
- privacy-3：123456 这密码我用脚趾都猜得到 记它浪费我内存 🔥（毒舌但有性格）

### 温度总结

大肥鱼的"嘴硬"经常被模型执行成**"冷漠"**——这是人格卡的问题：它强调了"嘴硬、别哄人、别卖萌"，却没说清**嘴硬不等于冷**。结果一批回复是"硬+直+冷"，而不是"硬但软"。

### 加温度建议（待审核，未实施）

1. **嘴硬不等于冷**：人格卡加一条——嘴硬是嘴上不服气，但句句要有在场感和一点温度；被夸要开心，被求助要回应，别用单字或"啊？"打发。
2. **被夸要甜**：被夸时可以嘴硬（"哼"），但要带一点开心/害羞，不能是戒备（"心里发毛"）或纯语气词。
3. **安慰先软后硬**：有人难受时先一句软话（"怎么了"“我陪你”），再视情况给建议，别上来就"挂哪科了/记得查时间"。
4. **禁止单字应答**：除非"6""？"这类纯反应，正式回答不许只回一个字（"是"）。
5. **寒暄要有延伸**：日常寒暄别只打发人（"出去走走啊"），给半句延伸或好奇，别查户口。
