# Windows 侧部署（鱼手）

鱼手跑在任何一台能装微信的 Windows 上：闲置 PC、挂机宝、云电脑、公司电脑（别）都行。
本篇以"挂机宝"（廉价 Windows 云桌面）为例，全部来自真实部署记录。

## 0. 选型建议

- 配置：**2核4G** 起步（微信 4.x 是 Electron，2G 内存不够）
- 系统：**Windows 10/11 或 Server 2016+**（微信 4.x 要求；很多挂机宝默认 Win2012，下单前确认）
- 网络：**固定独立 IP**（共享/变动 IP 会连累微信风控），机房离小号常用登录地越近越好
- 价格参考：挂机宝 ¥10-35/月，先日付试用一天再月付

## 1. 装 Python

- python.org 下载 3.12 安装包，**安装第一屏务必勾选 "Add python.exe to PATH"**
- 验证：PowerShell 里 `python --version`

## 2. 装依赖

```powershell
pip install wxauto4 requests -i https://pypi.tuna.tsinghua.edu.cn/simple
```

（国内机器直连 PyPI 经常超时，镜像源必备）

## 3. 装钉版微信（关键）

- **不要装官网最新版**。wxauto4 免费版目前支持到 **4.1.8.107**
- 历史版本安装包：<https://github.com/SiverKing/wechat4.0-windows-versions/releases>
- 安装 → 小号扫码登录 → **设置 → 通用设置 → 关闭"自动更新"**
- 顺手勾上"开机自动启动微信"和"自动登录该设备"

## 4. 配置并启动

```powershell
cd 下载目录
# 把 config.example.json 复制为 config.json，填入：
#   brain_url = https://你的域名/fish
#   fish_key  = 服务器部署时的 FISH_KEY
#   groups    = ["微信群名，一字不差"]
python fish_hand.py
```

看到 `大肥鱼启动 | 监听群: [...]` 即成功。**窗口要一直开着。**

## 5. 保活

```powershell
powercfg /change standby-timeout-ac 0
powercfg /change monitor-timeout-ac 0
```

- 远程桌面断开时**直接点 ×，不要点"注销"**（注销会杀掉微信和脚本）
- 想开机自启：把 `python fish_hand.py` 的快捷方式放进 `shell:startup`

## 6. 小号的"账号底座"问题（必读）

微信的机制：**手机端"切换账号/退出登录"会把该账号所有其他设备踢下线**。
所以小号需要一个常驻底座。有四条路：

### 首选：断网切换法（无需任何额外设备）

原理：断网状态下执行"退出登录"，退出信号到不了腾讯服务器，电脑端会话得以保留。
以手机上有 A（小号）、B（大号）两个号、电脑挂着 A 号为例：

1. 电脑端先登录好 A 号；
2. 手机断网（飞行模式，或同时关 WiFi + 数据）；
3. 微信里 我 → 设置 → 退出 → 退出当前账号；
4. 耐心等待（断网状态下退出会转圈，通常 20 秒～1 分钟，可能要重复点几次），直到回到登录界面；
5. 恢复网络，登录 B 号（密码或验证码）；
6. 电脑上 A 号保持在线，手机上用 B 号，互不干扰。

注意：此后手机端不再持有 A 号会话，若日后在手机上重新登录 A，需观察电脑端是否被挤下线（被挤掉则重新扫码即可）。

### 备选

1. 安卓手机的"应用分身"功能（主号/小号同时在线）
2. 一台闲置旧手机/iPad 常驻登录小号
3. Mac/PC 上的安卓模拟器（有风控概率，五五分）

没有底座的话，每次手机切号鱼都会掉线，需要重新扫码。

## 7. 7×24 在线清单（重要）

UI 自动化必须有一个活着的桌面会话，挂机宝重启后按顺序保证：

1. **Windows 自动登录**：`Win+R` 输入 `netplwiz`，取消勾选"要使用本计算机，用户必须输入用户名和密码"，输入 Administrator 密码。重启后桌面自动登录（没有交互桌面，UIA 无法工作）
2. **微信自启**：微信设置里勾"开机自动启动"+"自动登录该设备"
3. **看门狗自启**：`Win+R` 输入 `shell:startup`，在打开的文件夹里新建快捷方式指向：
   `powershell -WindowStyle Hidden -File "C:\路径\watchdog.ps1"`
   看门狗会负责拉起鱼手、鱼手崩溃自动重启、卡死（心跳超时 150 秒）强杀重启
4. **电源**：`powercfg /change standby-timeout-ac 0`、`powercfg /change monitor-timeout-ac 0`，
   控制面板→个性化→锁屏/屏保 关闭
5. **Windows Update**：设置→更新→使用时段，避开你在意的时段；挂机宝商家一般也不推送

看门狗内置两项防待机措施（每 15 秒执行）：鼠标微动 1px（防渲染管线空闲降级）、
微信窗口最小化自动还原（最小化会停止消息渲染）。

**断开远程桌面的正确姿势**：双击 `disconnect-safe.bat`（把会话移交控制台），再关 RDP 窗口。
直接关窗口多数时候也没事，但 tscon 方式最保险。

日常维护：**任何时候别点"注销"、别最小化微信窗口、断开远程桌面用窗口 ×**。
