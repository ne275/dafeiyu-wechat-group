# dafeiyu-wechat-group

[English](README_EN.md) | 中文

在微信群中运行一个由 DeepSeek 驱动的 AI 角色（"大肥鱼"，DeepSeek 蓝鲸图标的社区二创形象，非官方）。项目采用脑手分离架构：推理与决策全部位于用户自有的 Linux 服务器，Windows 端仅通过官方 PC 客户端的 UI 自动化收发消息，不注入进程、不使用非官方协议、不修改客户端。

> **项目性质声明**：本项目是一个学习样本与技术探索记录，而非生产级方案。作者明确认为该路线条件苛刻、前景有限，详见下文「定位与局限」。请在使用前完整阅读。

## 架构

```
┌─────────────────────────────┐         ┌──────────────────────────┐
│  Linux 服务器（脑）           │         │  Windows 机器（手）        │
│  brain/  FastAPI + DeepSeek │ ◄HTTPS► │  hand/  wxauto 轮询脚本    │
│  · 人格卡与热梗词典           │  密钥    │  · 官方 PC 微信客户端      │
│  · 活跃周期决策模型           │         │  · 无注入、无协议          │
│  · 记忆沉淀与聊天日志         │         │  · UI 自动化收发消息       │
│  · 定时消息（早晚安）         │         │                          │
└─────────────────────────────┘         └──────────────────────────┘
```

设计动因：个人微信的自动化接入在技术上仅有三类路线——协议模拟、客户端注入、UI 自动化。前两类分别面临平台风控与法律压力（已有多起下架与封禁先例）。UI 自动化不接触客户端内部状态，是三者中风险最低的一类，但其代价是必须维持一个真实 Windows 桌面会话。因此项目将计算与状态集中于服务器，Windows 端退化为无状态的哑终端，从而降低单点失效的修复成本。

## 定位与局限

本节是对项目能力边界的如实说明，构成本项目文档不可分割的一部分。

**部署条件苛刻。** 完整运行需要：

1. 一台持续在线的 Windows 机器（实体机、云桌面均可），专用于运行微信客户端；
2. 一个微信小号，且该账号需要常驻的手机端登录状态（备用设备或系统应用分身），否则手机端切换账号将导致全部会话失效；
3. 微信客户端版本须锁定在自动化库支持的范围内，并禁用自动更新。

**路线前景有限。** 个人微信自动化整体处于平台持续收紧的空间内：官方接口当前仅覆盖私聊场景；多个第三方协议实现已因平台措施而停止维护；UI 自动化依赖客户端界面结构，微信的版本更新可能随时使其失效。本项目不对长期可用性作任何保证。

**回复逻辑为初级实现。** 具体而言：

- 发言决策为单层 LLM 判断，无"低成本预筛 + 生成"的两阶段结构；
- 无检索增强、无工具调用、无图像理解（图片与表情仅以占位文本表示）；
- 长期记忆为周期性滚动摘要，而非检索式记忆；
- 全部概率与阈值参数（唤醒概率 0.05、主动插话间隔 25 秒等）均为经验值，未经系统调优；
- 人格表现完全依赖提示词工程，未做任何模型微调。

**项目价值。** 一份可运行、注释完整、如实记录缺陷的参考实现。适用于：希望理解群聊 AI 工程难点的开发者；在自有小群内进行娱乐性部署的用户；以及希望在此基础上继续改进的后来者。

## 功能

| 功能 | 说明 |
|---|---|
| 人格系统 | 社区角色设定（含网络热词词典），可按文件替换 |
| 群聊触发 | 提及角色名必答；引用其历史发言视为追问（免@）；单独呼叫名字有应答 |
| 记忆 | 每群定期沉淀"近期话题 + 成员印象"摘要并注入后续对话 |
| 主动发言 | 活跃周期模型：被唤醒后由 LLM 判断每条消息是否接话；连续判定不接则自动退出活跃状态 |
| 自我感知 | 模型可见自身历史发言（避免重复表达）；无法识别的媒体类型如实声明 |
| 输出整形 | 双层括号内文本视为草稿不发送；元叙述句自动移除；超长回复自动压缩 |
| 定时消息 | 每日固定时段主动发言（早安、催睡） |
| 聊天日志 | 按会话与日期持久化（JSONL），提供查询接口 |
| 安全机制 | 每日发言上限、主动发言最小间隔、接口密钥鉴权 |

## 快速开始

前置条件：Linux 服务器一台（Docker）、Windows 机器一台、微信小号一个、DeepSeek API 密钥一个。

```bash
# 服务器（鱼脑）
cd brain
FISH_KEY=$(openssl rand -hex 24) DEEPSEEK_API_KEY=sk-xxx docker compose up -d
# 经反向代理以 HTTPS 暴露，详见 docs/deploy-server.md

# Windows（鱼手）
pip install -r hand/requirements.txt
cp hand/config.example.json hand/config.json   # 填写 brain_url / fish_key / 群名
python hand/fish_hand.py
```

## 风险与可接受使用

- 微信的服务条款不允许未经授权的自动化。UI 自动化是当前各类路线中对客户端侵入性最低的一类，但风险不为零。请使用小号并控制发言频率。
- 仅可用于你有权使用的账号、会话与数据。禁止用于营销、群发、骚扰或未经授权的信息收集。
- 群聊内容将发送至第三方模型服务。建议事先告知群成员该会话中存在 AI 参与者。
- 依赖的 wxauto 免费版当前支持微信 PC ≤ 4.1.8.107，安装客户端后须立即禁用自动更新。
